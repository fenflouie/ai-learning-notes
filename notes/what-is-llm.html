什麼是 LLM？大型語言模型入門

2026 年 11 月 15 日
LLM 基礎觀念

什麼是大型語言模型（LLM）？

大型語言模型（Large Language Model，簡稱 LLM）是一種基於深度學習的 AI 模型，透過大量文字資料進行訓練，能夠理解並生成自然語言文字。常見的 LLM 包括 OpenAI 的 GPT 系列、Google 的 Gemini、Anthropic 的 Claude 等。

ℹ️ 補充：「大型」指的是模型的參數量非常龐大，通常達到數十億甚至數兆個參數。

LLM 的運作原理

LLM 的核心概念是「根據前文預測下一個字」。模型在訓練過程中閱讀了大量文本，學會了語言的統計規律。當你給它一段文字（稱為 Prompt），它會根據學到的規律，逐字生成最可能的回應。

簡化的運作流程

  1. 輸入（Input）：使用者提供一段文字提示（Prompt）
  2. 分詞（Tokenization）：將文字切分成 Token（詞彙單元）
  3. 模型推理（Inference）：模型計算每個可能的下一個 Token 的機率
  4. 輸出（Output）：選擇機率最高的 Token，逐步組成回應
💡 提示：Token 不一定等於一個字。在中文中，一個字通常是 1-2 個 Token；在英文中，一個單字可能是 1-3 個 Token。

LLM 的主要應用

應用領域 說明 範例
文字生成 撰寫文章、郵件、報告 ChatGPT、Claude
程式輔助 產生、解釋、除錯程式碼 GitHub Copilot、Cursor
翻譯 多語言互譯 Google Translate (AI 版)
摘要 將長文縮短為重點 NotebookLM
問答系統 回答知識性問題 Perplexity AI

用 Python 呼叫 LLM API

以下是使用 OpenAI API 呼叫 GPT 模型的基本範例：


from openai import OpenAI

client = OpenAI(api_key="your-api-key")

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "你是一個友善的 AI 助手。"},
        {"role": "user", "content": "請用一句話解釋什麼是 LLM。"}
    ]
)

print(response.choices[0].message.content)
⚠️ 注意：請勿將 API Key 直接寫在程式碼中，建議使用環境變數來管理敏感資訊。

LLM 的限制

  • 幻覺（Hallucination）：LLM 可能會生成看起來正確但實際上錯誤的內容
  • 知識截止日：模型的知識有截止時間，不知道訓練資料之後發生的事
  • 上下文長度限制：一次能處理的文字量有限（雖然不斷增加中）
  • 推理能力：在複雜邏輯推理上可能犯錯
